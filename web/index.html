安装界面、兼容说明与安全细节 ＋

屏幕大小自动适配：默认自动推荐，结合当前窗口所在屏幕的物理像素和 Windows 缩放：1080p／100% 推荐 64px、1440p（2K）推荐 96px、4K 推荐 128px；高缩放取更大的档位，不重复相乘。也可手选 32／48／64／96／128px。每帧含对应尺寸，应用时精确选取，像素风保持硬边，不用平滑插值，也不凭空增加原画细节。多屏移动窗口会刷新推荐，点击主题应用后才生效；关闭软件后跨屏显示仍由 Windows 管理，不安装全局鼠标钩子。

HDR 保持开启：安装 Windows 2.5，勾选「HDR 指针偏白补偿（实验）」，选好强度后重新应用主题。100% 为标准逆 sRGB 补偿；若过深可试 50%。默认关闭，只处理本地指针，不改整屏色彩、ICC 或 HDR 开关。原包、动画、透明度与热点保留不变。此功能尚待发生问题的 HDR 电脑实测，不代表通用色彩校准；混合 HDR / SDR 多屏需逐屏核对。

以上为 C# 离屏渲染，不是 Windows 实机截图。自动测试和格式校验已通过，Windows / macOS 真机安装、动画、高 DPI 与重新登录效果仍待验收。Windows 安装包未签名，请勿关闭系统安全保护。

云端只同步目录和素材，不执行远程指令、不静默更新 EXE。旧版软件需要下载新版安装包，「同步目录」不会升级程序。基础像素版与嘉然功能精修版的细节数量在主题详情中分别说明。
