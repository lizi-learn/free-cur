# Code and artwork have different rights

The MIT license applies to the original Free Cur source code and project documentation.
It does not grant rights to third-party characters, names, trademarks, reference
illustrations or the character artwork under `artwork/` and in generated packages.

The pixel character sheets are AI-assisted, unofficial fan reinterpretations.
They are not official sprites or a claim of an independent commercial license.
Original character rights remain with their respective rights holders. The
project cannot grant rights it does not own. The repository's code license must
not be presented as permission to commercially reuse those characters or images.

`sources.json` preserves the public reference page, original image URL, retrieval
date and image checksum for each active character. Reference illustrations are
not bundled here. Each pixel directory preserves its prompts, generated sheet,
processed frames and provenance. References to absent identity images in provenance
are resolved through `sources.json`; those images are not needed to build the
included pixel themes. Generated theme packages retain `SOURCE-AND-RIGHTS.txt`.

The included characters are from A-SOUL, EOE, 星瞳, 阿梓, 四禧丸子 and 永雏塔菲.
This project is independent of their creators and operators. Encyclopedia text
licensing is not assumed to cover the reference illustrations.

Third-party build tools and dependencies keep their own licenses. Microsoft
.NET Framework reference assemblies, Mono, NSIS, Xcursor, Pillow, requests,
sharp and Mousecape are not relicensed by this repository. Mousecape itself is
not bundled. Downloaded toolchains and compiled packages are excluded from Git.

For source issues or a rights-holder request, open an issue at
https://github.com/lizi-learn/free-cur/issues with the affected file or theme and
the requested correction. Do not post personal credentials or sensitive information.
